# Pinned native syntax inputs

This directory is source code and licensed query data, not runtime downloads.
`build.rs` verifies the recorded SHA-256 values and statically compiles the native
C/C++ parsers and scanners. The application uses Rust Tree-sitter 0.25.10; it does
not load WASM, start Node/Bun, or fetch a parser at build/runtime.

## Inventory and attribution

The authoritative per-file inventory is `manifest.json`: repository, immutable
commit, release/reference WASM URL, complete source-archive digest, native entry
point, scanner paths, parser aliases, configured query sources and their digests,
query-source licenses, actual file-extension and info-string resolution inputs.

- OpenCode donor: `anomalyco/opencode`, commit
  `2670273ff17da96f85c5826ced57aa1b368754fa` (v2.0.12).
- OpenTUI: `anomalyco/opentui`, commit
  `f6673a04ccb671b9207da358c57152bfd27c781f` (0.5.10).
- Floating nvim query inputs frozen at
  `cf12346a3414fa1b06af75c79faebe7f76df080a`.
- Full inventory: 34 externally configured grammars plus five actual OpenTUI
  built-ins: JavaScript, TypeScript, Markdown, Markdown inline and Zig.

Each `{language}.tar.gz` retains the byte-exact generated parser/scanner sources,
relative headers, node-type metadata and repository license/COPYING files. They
remain third-party source under those original licenses; packaging is deterministic
and excludes repository history/tests/binaries. `license-*` files retain the
byte-exact licenses for query-source repositories. Keep all attribution and
license bytes when updating inputs. The manifest lists their original paths and
digests; it does not replace the original notices.

`scripts/syntax_assets.py` is a development importer, not a build/runtime tool.
It reads actual donor/OpenTUI descriptors and freezes their direct query inputs.
OpenTUI does not expand Neovim `inherits` comments or execute locals/custom Lua
directives; importing them as additional behavior would change the oracle.

## Explicit source/version qualifications

Swift 0.7.1 does not commit generated C. Its exact tagged source is generated with
Tree-sitter CLI 0.23.2/ABI 14, recorded in the manifest. The configured floating
`main` highlight query now belongs to 0.7.4 and fails against the actual reference
0.7.1 WASM (`unsafe_expression` is absent). Both native and development-reference
fixtures therefore freeze the official **same-release** 0.7.1 query, with the
original URL and reason recorded as `reference_query_freeze`. No query pattern is
invented, removed or renamed to hide an incompatible grammar.

Nix's reference is an ast-grep WASM at its configured immutable commit; the native
source candidate and commit are separately recorded. Its version/ABI is not
claimed byte-identical to that WASM. Swift likewise has differing generated ABI/
node inventories. Their observable capture/style behavior is checked against the
actual reference assets, not inferred from a release label or native goldens.

## Actual-reference fixtures and shared behavior

`fixtures.json` contains two finite representative sources per required grammar:
language-specific constructs, multiline/partial inputs, Unicode and overlapping
captures. `fixtures.reference.json` is generated by
`scripts/syntax_reference_corpus.ts` using the real pinned OpenTUI worker,
Web Tree-sitter assets, donor theme resolution, native `SyntaxStyle` and its actual
text-chunk converter (conceal disabled). It records all actual WASM digests, source
and manifest digests, token byte boundaries/names/injection metadata and dark/light
fg/bg/attributes. Native tests compare all 78 cases/156 styled projections without
flattening overlaps, discarding empty captures or changing literal code text.

This corpus is a reproducible SDK/source qualification, **not** a claim of whole
T44 pixel parity or a replacement for actual original/native TUI qualification.
Shared Markdown and patch rendering use one bounded native token owner; cache
keys include full source and grammar, not theme/width. Indexed fences preserve
whole-fence context and literal CommonMark text. Known resource/asset failures are
explicit preview diagnostics; only genuinely unregistered languages fall back
without claiming grammar coverage.
