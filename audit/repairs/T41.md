# T41 — Пересобрать доказательства вокруг бинарника

Audit commit: `fc796830cf336655bebf63b591fe0fd36cdd4310`. Findings: F18. Эти требования уточняют существующие A01–A13, не расширяют продуктовый scope.

## Что исправить

Компонентные suites сохранить, но добавить строгий binary-level fake harness: real config loader, chosen model, two function-call rounds, patch, shell tests, webfetch, MCP, модельный compress, process exit/restart и configured-workspace A→B. Fake проверяет requests/roles/call IDs и временной порядок, а не отвечает успехом на любой текст. Ни один обязательный шаг нельзя заменить прямым вызовом Rust helper из теста.

Test evidence содержит commit, команду, exit, attempted/executed/passed/failed/skipped/blocked counts и причину. Rust ignored test с ранним return при отсутствии env не является live PASS. При explicit запуске обязательного live harness missing credentials должен давать machine-readable blocked/non-success; обычный offline suite по-прежнему может не запускать ignored live tests.

Подготовить bounded live campaign на том же executable path без автоматического прогонки всего model catalog. Сохранить существующий user-approved budget; watchdog контролирует каждую generation/call и общий campaign. Поддержать обязательный codex_web: отсутствие дополнительного LUDKA2_MCP_URL не должно молча убрать сервер, уже настроенный в opencode.jsonc. Model eligibility/limits берутся из реального catalog, а не придуманного context=1_000_000 в тесте.

Отделить ошибки harness/protocol от model variance; не объяснять broken wire «слабой моделью» до strict fake. Partial live успех можно честно сохранить, но READY требует полного согласованного прохождения. Не менять mocks под текущие bugs.

## Критерии приёмки

### AUD35 — One binary golden workflow

Executable fake campaign проходит A01–A13 paths: effective config → Responses/tool loop → file/tests → MCP → model compress → process restart → workspace switch. Outbound/side effects/terminal states проверяются независимо.

### AUD36 — Evidence cannot pass by skipping required work

Explicit mandatory harness при missing creds/MCP emits BLOCKED/non-success. Aggregate не преобразует ignored/skip/early return в PASS. Unexecuted cases и их причины присутствуют в JSON/report.

### AUD37 — Bounded live harness ready before paid run

Live campaign использует product binary/config/catalog, existing counters/watchdog/budget, exact chosen model/variant; compulsory MCP не optional skip. Все harness branches предварительно испытаны offline, без покупки live retries.
