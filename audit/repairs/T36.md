# T36 — Подключить DCP к реальному tool loop

Audit commit: `fc796830cf336655bebf63b591fe0fd36cdd4310`. Findings: F07. Эти требования уточняют существующие A01–A13, не расширяют продуктовый scope.

## Что исправить

Зарегистрировать compress как обычный native tool через общий permission/durable dispatcher. Его model-visible schema и message/block anchors должны быть доступны модели в текущем context projection. Зарегистрировать glob/grep там же либо завершить wiring их существующих adapters; standalone helper не является доступным model tool.

Nudge добавляется в реально отправляемый prompt по правилам текущего DCP config, а не только возвращается в TurnReport. Проверить turn/iteration/cadence/manual mode/reset после compress; состояние привязано к сессии, не смешивается между разными sessions Runtime. Dedup/purge errors участвуют в том же projection transaction и действительно меняют следующий request.

Compression ranges должны коммититься одной логической транзакцией с memberships/protected content. Compensating deletes после ошибки не эквивалентны crash atomicity. Savings считать только по реально заменённому projected контенту; no-gain не должен записывать misleading success. Сохранить вложенные summaries и protected user/tool/file contents; DCP protectedFilePatterns защищают от удаления из контекста, а permission policy отдельно решает доступ к filesystem. Не смешивать эти две защиты.

Ни raw history, ни provider call/result integrity не должны повреждаться. Пройти модельно инициированный compress → новый request меньшего активного контекста → restart → продолжение с сохранённым фактом. Тестовый код не имеет права вызвать run_compress вместо модели и объявить этот тест доказательством model tool support.

## Критерии приёмки

### AUD19 — Compress/glob/grep are actually exposed

Captured real binary request содержит admitted compress/glob/grep schemas. Fake вызывает compress с валидными anchors; общий dispatcher выполняет его и отдаёт structured output.

### AUD20 — Nudges and automatic strategies reach the model

В captured request видны своевременные nudges; после model compress соблюдаются cooldown/manual rules, dedup и purgeErrors меняют только заявленные части, error messages сохранены. Counters из другой сессии не влияют.

### AUD21 — Compression is durable and accurately reported

Crash во время multi-range change не даёт половину projection. No-gain не считается сэкономленными tokens всей истории. Protected/nested facts и raw transcript сохраняются; после process restart следующий request корректен.
