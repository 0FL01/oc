# T34 — Настоящий Responses protocol и streaming

Audit commit: `fc796830cf336655bebf63b591fe0fd36cdd4310`. Findings: F02, F03. Эти требования уточняют существующие A01–A13, не расширяют продуктовый scope.

## Что исправить

Заменить плоский string prompt на typed input items. Разделить provider item_id и function call_id. Следующий запрос несёт полные завершённые function_call items и function_call_output с правильным call_id, а также допустимые messages/images и opaque continuation items. Не восстановлять reasoning из отображаемого текста. Store:false не освобождает клиента от владения историей. Точные необходимые поля проверять против pinned OpenProxy и официального wire contract; не добавлять универсальный protocol translation layer.

SSE state machine различает completed, incomplete, failed, transport EOF и cancellation. Завершённый JSON chunk не равен завершённой generation. При отсутствии успешного terminal marker нельзя отдавать Completed или запускать недособранный batch. Ограничить pending line/event/arguments/total retained bytes, а не только число событий. Runtime должен отдавать bounded deltas application consumers во время генерации, не только Generation после EOF.

Cancellation должна прерывать DNS/header/body waits, tool execution и MCP attach. Chunk timeout читать из effective config; timeout:false означает отсутствие total generation deadline, но не неотменяемость. max_output_tokens и setCacheKey должны соответствовать выбранным options; сохранить extra headers с правильной политикой. Max rounds исчерпан → явный limit/incomplete outcome, не Completed. Не делать retry 400/invalid payload как generic transport; после commitment/side effects не запускать скрытый replay. Предпочтение пользователя 100-minute idle сохраняется, локальные тесты используют короткие bounds.

## Критерии приёмки

### AUD09 — Strict function_call continuation

Fake выдаёт item_id=fc_A и call_id=call_B. Второй запрос обязан содержать function_call_output.call_id=call_B и replayable output items. Подмена обычным user text или item_id отвергается fake-сервером.

### AUD10 — Reasoning/images/restart wire integrity

Store:false два tool rounds и новый process сохраняют необходимые opaque items без их UI/log раскрытия. Input image реально присутствует в wire, либо выбранная неподдержанная modality получает explicit diagnostic; A04 не закрывается только helper test.

### AUD11 — Terminal and budget outcomes

Оборвать stream после корректного text event без completed; передать response.failed/incomplete; исчерпать max rounds. Ни один случай не Completed. Incomplete call не исполняется, уже совершённый результат не теряется/не повторяется.

### AUD12 — Cancellation and actual streaming

Fake посылает один chunk, затем молчит. Cancel завершает turn за тестовый bound, не ожидая chunkTimeout. Отмена работает и до headers. Первый delta виден процессу/PTY до terminal event.

### AUD13 — Bounds and effective options

Длинная незавершённая SSE line, oversized args/event/request ограничены по bytes без пропорционального роста. Custom chunkTimeout, max_output_tokens, headers и setCacheKey проверяются по captured request/clock. 400 не auto-retry.
