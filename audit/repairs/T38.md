# T38 — Shell и webfetch без hangs/Unicode panic

Audit commit: `fc796830cf336655bebf63b591fe0fd36cdd4310`. Findings: F12, F13. Эти требования уточняют существующие A01–A13, не расширяют продуктовый scope.

## Что исправить

В shell запустить stdin writer и оба output drainers конкурентно под общей supervision. Deadline начинается до spawn/write, cancellation доступна на всех wait. Завершение leader не означает завершение процесса-группы или EOF pipe. Ограниченный cleanup должен работать, когда descendant держит stdout, игнорирует TERM или leader завершился раньше. После grace — cleanup только собственной группы; не зависать на join бесконечного reader. Бounded outputs продолжают drain/discard со счётчиком. Resolve cwd учитывает symlinks. Предусмотреть рабочие cargo/rustc/dev-tool paths без восстановления всех provider/runner secrets в child env; «название env не содержит token» не является строгим allowlist.

Webfetch: Unicode-safe HTML extraction. Использовать поддерживаемый URL parser/join вместо нескольких ручных split; учитывать relative/protocol-relative redirect, IPv6, query/fragment и запрет userinfo/нужных схем. Проверенный DNS address должен определять фактическое соединение до отправки request. Post-response remote_addr не предотвращает уже выполненный запрос к private endpoint. Сохранять TLS hostname validation при pinning IP. Провайдер/MCP trusted endpoint exceptions не распространяются на произвольный model webfetch.

Один total fetch budget охватывает DNS, каждый redirect и body; quotas по bytes независимы от Content-Length. Auth не наследуется на другой origin, и provider bearer не становится глобальным credential для webfetch. No-network unit tests + scoped loopback integration, no обращения к реальным private/metadata hosts.

## Критерии приёмки

### AUD25 — Unicode HTML and standard URL handling

html_to_text("<p>Привет 🦀</p>") не panic и сохраняет текст. Проверить entity handling, malformed HTML, relative redirects, query-only URLs и IPv6; никаких lossy byte-as-char преобразований.

### AUD26 — Dial-bound egress and total deadline

Контролируемый resolver меняет public→loopback/private между lookup и connect: запрещённый destination не получает HTTP request. Redirect не обходит policy; headers не текут. Deadline общий на все hops.

### AUD27 — Stdin/output deadlock and orphaned pipe

В отдельном subprocess под outer watchdog: child не читает большой stdin; child сначала пишет большие stdout/stderr; leader выходит, descendant держит pipe/игнорирует TERM. Timeout/cancel завершается в bound и owned descendants убраны.

### AUD28 — Working toolchain with minimal environment

Обычные fixture cargo/rustc commands работают в production tool path без абсолютных подсказок, добавленных только тестом. Provider/MCP/runner credentials не наследуются; symlink cwd escape отклонён.
