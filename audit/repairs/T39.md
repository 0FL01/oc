# T39 — Довести TUI до подключённого daily workflow

Audit commit: `fc796830cf336655bebf63b591fe0fd36cdd4310`. Findings: F14. Эти требования уточняют существующие A01–A13, не расширяют продуктовый scope.

## Что исправить

Использовать уже существующие picker/pager/workspace/DCP components, но связать их с настоящим event loop и application queries/actions. Panel navigation, render и model/variant/session/agent selection должны менять effective state. UI не владеет второй DB-backed session logic и не дублирует config registry.

Добавить PTY тесты обычного бинарника с isolated HOME и fake provider/MCP. Проверять /model, /sessions, /skills, primary-agent selection, пользовательские commands и /dcp-compress. Tool cards/diff и approval/error/unknown states получают данные из runtime. Смена session во время turn либо сериализована, либо явно отклоняется; не терять active task.

Обработать bracketed paste как event, Unicode grapheme editing в пределах поддержанного editor, resize, slow output и terminal restoration на всех ошибках. Реальный renderer не должен показывать только две Paragraph при открытом picker. Input сохраняется после application acceptance, не после любой клавиши Enter.

Paged/bounded history применяется к backing state, а не только viewport. Лимиты по bytes и rows; нет Vec всей истории или накопления всех посещённых sessions. Конкретные storage types убрать из presentation API там, где иначе появляется второй owner, но не устраивать косметическую массовую перестановку модулей.

## Критерии приёмки

### AUD29 — Actual PTY panels and workspace operations

PTY запускает target binary и клавишами выбирает model/variant/agent/session, открывает skills, dispatches custom command и DCP. Request/runtime state реально меняется; screenshot/render helper отдельно недостаточен.

### AUD30 — Paste/cancel/resize/error terminal recovery

Bracketed paste, Cyrillic/emoji, resize во время stream, Ctrl-C и ошибочный output handle завершаются корректно. Тест подтверждает terminal flags/restoration и отсутствие лишних persisted user messages.

### AUD31 — Paged UI backing state

Длинная история и переходы между многими sessions не увеличивают UI retained bytes пропорционально архиву; старые страницы выгружаются, нужные tool cards не ограничены первыми 200 старейшими записями.
