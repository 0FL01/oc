# T35 — Configured workspace и точный discovery

Audit commit: `fc796830cf336655bebf63b591fe0fd36cdd4310`. Findings: F08, F09, F17. Эти требования уточняют существующие A01–A13, не расширяют продуктовый scope.

## Что исправить

Глобальные XDG/config roots и project roots обнаруживаются production loader, а не передаются вручную только из тестов. Зафиксировать порядок pinned baseline и названные отличия. Support включает opencode.json/jsonc, AGENTS.md, skills/<id>/SKILL.md, agents/commands Markdown и допустимые inline definitions. Не изобретать inline filenames вместо уже заданных config domains без authoritative fixture. Исходные файлы read-only.

AgentDef хранит body/prompt и поддержанные metadata/permission narrowing, а snapshot digest меняется при изменении поведения. Выбор primary agent реально меняет request, не только строку picker. Не расширять scope на subagents. Commands — буквальные templates: Markdown backticks, слова subagent и примеры shell не являются исполнением. Только распознанный executable upstream syntax либо поддерживается безопасно в рамках scope, либо отклоняется точной diagnostic. Подстановки $ARGUMENTS/$1 не обрабатывают вставленный аргумент повторно.

Skills публикуются из одной generation: metadata для discovery, body только при explicit skill tool, snapshot неизменяем в turn. Недопустимое frontmatter не становится silently valid. Unknown capability не теряется при deserialize. Известные native plugin markers привязывать явно; arbitrary JS/TS не исполняется. Нельзя считать basename совпадение доказательством behavioral equivalence модифицированного локального плагина — нужна явно объявленная native binding/диагностика.

Нормализовать legacy write/edit policy к apply_patch ДО merge/проверки; restrictive conflict не ослабляется. Тестировать финальный executor. Source-relative {file:} и raw-text substitutions сверять с baseline, source provenance не должен указывать старый файл после override. Disabled integrations не вызывают process/network и не требуют ненужных secrets; selected integration не работает с пустыми credentials.

Discovery: использовать ровно пользовательский JS oracle из locked snapshot. Исправить Number.MAX_SAFE_INTEGER boundary (2^53-1), multi-slash naming, HeaderMap case-insensitive replacement, query/fragment/userinfo URL validation стандартным parser. Сохранять user snapshot overrides, 15s/30s/retries, atomic replace и no hardcoded model IDs. Отличия в cosmetic name нельзя ставить выше core protocol safety.

## Критерии приёмки

### AUD14 — Global/project configured workspace through binary

Запустить oc в A и B с общими global и разными project configs/AGENTS/skills/agents/commands. Captured request доказывает правильный порядок, один экземпляр инструкции, отсутствие A-local content в B и запрет cross-Location session.

### AUD15 — Agent prompt and literal commands

Два primary profiles с одинаковой description, но разными body дают разные snapshots и requests. Command с `cargo test` и code fence загружается буквально, не исполняется loader; аргумент с $2 не переинтерполируется.

### AUD16 — Legacy deny and untrusted configuration

permissions apply_patch=allow плюс legacy write/edit=deny не разрешают patch. Аналогичная agent-specific narrowing применяется. Unknown dangerous fields и untrusted substitutions дают diagnostics до side effect; исходный config unchanged.

### AUD17 — Native plugins and skill snapshot

Known bound DCP/discovery marker активирует ровно один compiled module без JS. Unknown plugin диагностируется; модельный skill возвращает pinned body, не новый reread. Missing/malformed/oversized definitions не становятся silent defaults.

### AUD18 — Discovery oracle edge cases

Сравнить Rust и locked user oracle: 2^53 rejected, multi-slash IDs/display names, conflicting header spellings, missing credentials, empty/retryable envelopes, removed IDs, static ludka limits not clamped. Нет remote override URL/options/SDK.
