# T37 — MCP config, registry и владение ресурсами

Audit commit: `fc796830cf336655bebf63b591fe0fd36cdd4310`. Findings: F10, F11. Эти требования уточняют существующие A01–A13, не расширяют продуктовый scope.

## Что исправить

Принять header spelling из исходного пользовательского примера Authorization. Не делать lowercase-only lookup в BTreeMap. Нормализовать headers один раз в typed HTTP HeaderMap, отклонять неоднозначный conflicting duplicate. Credentials не входят в model-visible config/logs.

Сохранять rmcp, не заменять SDK самописным JSON-RPC стеком. Codex_web strict POST/JSON 2025-11-25 no-session path должен проходить с точным configured URL; oauth:false не запускает OAuth. Optional GET 405 не ломает корректный POST. search args брать из фактической server schema: pinned OpenProxy принимает query/response_length, не выдуманный limit.

Clients живут на Location/config generation. Второй turn не запускает npx и initialize заново; reload/disable корректно закрывает старую generation. Client registry хранит точное соответствие wire name → original server/tool, а не восстанавливает его split_once("__") после collision renaming. Oversized каталоги возвращают явный limited/error, а не .take(64) с бесшумной потерей остатка. Unsupported result modality не становится пустым success text; isError и network failure различимы.

Stdio процесс запускается с retained argv, правильным cwd и минимальным рабочим env. Own process group/cancellation/reap охватывают npx wrapper и descendants; нельзя посылать signal группе runner. Не включать настоящий browser, не переписывать @latest автоматически. Disabled entry не запускается и не требует Node. Ограничить stderr и обеспечить cleanup при частичной attach failure/drop/cancel.

## Критерии приёмки

### AUD22 — User MCP config works unmodified

Собрать McpEntry из JSONC с headers.Authorization; initialize/list/call проходит strict fake. lowercase/mixed-case эквивалентны, conflicts диагностируются. Не делать OAuth/probing URL.

### AUD23 — Generation-owned lifetime and shutdown

Два turns одной generation создают один MCP child/handshake. Reload/disable/restart меняют ровно нужные ресурсы. Crash/failure/cancel cleanup не оставляет owned wrapper/descendants; disabled chrome zero-spawn.

### AUD24 — Registry and result semantics

Collision-prone names направляют вызов в правильный original server/tool. Oversized catalog видим. Неподдержанная modality и isError не success. Search request соответствует server schema, а не helper limit argument.
