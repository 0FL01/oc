# T32 — Исправить apply_patch до дальнейших мутаций

Audit commit: `fc796830cf336655bebf63b591fe0fd36cdd4310`. Findings: F04, F05. Эти требования уточняют существующие A01–A13, не расширяют продуктовый scope.

## Что исправить

Унифицировать model schema, parser и docs на одном поле `patchText`. Не оставлять параллельно `patch` и `patchText` без явной compatibility migration. Fixtures брать из pinned upstream и дополнить независимыми ожидаемыми bytes. Add File должен декодировать ведущий `+`; пустой Add создаёт 0-byte файл. Проверить Move to в допустимом upstream-порядке, Unicode/CRLF/no-final-newline, неоднозначные hunks, duplicate/overlapping paths.

Все детерминированные grammar/path/size/preimage/permission ошибки проверяются до первого изменения. Это НЕ обещание общей транзакции по всем файлам. Результаты и partial failures после реального I/O-сбоя должны перечислять уже совершённые операции, в том числе update, после которого не удался move.

Временный файл создаётся exclusively, без следования symlink и без предсказуемого переиспользования чужого inode. Использовать поддерживаемую библиотеку/OS primitives, а не очередной самодельный pathname guard. Для родительских директорий нужны handle-relative/no-follow операции или строго доказанная ограниченная политика; canonicalize до открытия не устраняет race. Final add/move не должен перезаписывать конкурентно появившийся target. Update должен проверять актуальность preimage перед commit; наружные изменения не затираются молча. Синхронизировать нужные file/directory boundaries согласно заявленной crash durability. Тесты preplanted symlink выполняются только в tempdir с безопасным outside-sentinel.

Не давать агенту ослабить regression assertions до текущего поведения ради зелёного результата.

## Критерии приёмки

### AUD03 — Upstream-style Add File bytes

Patch Add File с +hello создаёт ровно hello\n, не +hello\n; empty Add, Unicode и Update пустого файла корректны; parser/schema одинаковы.

### AUD04 — Temporary symlink and path confinement

Предсозданный symlink на ожидаемом temporary path, symlink parent и замена parent между validation/commit не меняют outside sentinel. Add/move не затирают concurrent target. Нет следования существующему temp inode.

### AUD05 — Preflight and honest partial outcome

Ошибка hunk/preimage в позднем файле выявляется до записи ранних файлов. Отдельный inject I/O failure после разрешённого первого commit возвращает failure с точными committed paths/hashes, не success и не обещание rollback.
