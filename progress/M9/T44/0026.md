# T44 — user message agent color

## Result

RECON traced the color reset to the accepted user echo being stored with no agent,
while durable history already exposes its turn's agent and categorical color index.
The prompt used the selected profile; the user row therefore fell through to palette
slot zero (Build). The source inventory confirms upstream user-message borders use
the agent color (`evidence/tui/upstream-inventory.md`, section 4).

The TUI now snapshots agent ID and color index with the immutable pending submission,
keeps them on its accepted user echo, restores both from `HistoryTurn` on replay, and
uses that pinned color in both transcript rendering paths. Legacy rows without turn
metadata retain the previous fallback. Changing the selected profile affects later
submissions without recoloring earlier rows.

Implementation and regression tests are in commit `6c245c4`.
