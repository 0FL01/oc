## Independent-review correction — HTTP status before body (same uncommitted HEAD)

The earlier scripted status tests and small-body binary PTYs missed a real transport defect: `ReqwestDiscoveryClient::get` read/limited the body before `fetch_models` classified the status. An oversized 401/403 became `InvalidResponse`; a delayed body could instead exhaust the attempt timeout and become `Network`. The authoritative `references/openproxy-models.user.mjs:105–113` checks `response.ok` and decides HTTP retry/termination **before** calling `response.json()` (line 115). Malformed configured baseURL is already rejected by composition before discovery and remains a general configuration failure; this correction does not change that ordering.

Test-first real HTTP fixtures returned 401/403 with >8 MiB bodies and headers before delayed bodies through the actual Reqwest client. `cargo test --locked -p oc-adapters reqwest_http_error_status_precedes_oversized_or_slow_body --lib -- --nocapture`: **101**, with an oversized 401 incorrectly classified `InvalidResponse`. Expanded isolated binary PTY fixture with oversized/slow 401/403 (plus the original normal-status/absent/present cases): `cargo test --locked -p oc --test recovery_startup isolated_discovery_startup_routes -- --nocapture`: **101**, with diagnostic output withheld by the Rust harness. These are retained red reproductions, not passes.

The transport now returns non-2xx status without consuming error-body bytes; `fetch_models` retains the existing retry classification. `cargo test --locked -p oc-adapters reqwest_http_error_status_precedes_oversized_or_slow_body --lib -- --nocapture`: **0**; `cargo test --locked -p oc --test recovery_startup isolated_discovery_startup_routes -- --nocapture`: **0**. Strengthened real-server assertions await all expected requests: 401/403 terminate on the first attempt; oversized 429/503 retain four attempts and `Http` classification; oversized **2xx** still fails the 8 MiB cap as `InvalidResponse`; delayed 401/403 status arrives within a short attempt timeout without waiting for the body. `cargo fmt --all && cargo test --locked -p oc-adapters reqwest_http_error_status_precedes_oversized_or_slow_body --lib && cargo test --locked -p oc --test recovery_startup -- --test-threads=1`: **0** per command (one transport test, all three startup tests).
