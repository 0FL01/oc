## Repair and effects

- Application assembly now receives the pinned admitted **root fd** and canonical source-directory path *relative to that root*, indexed internally by source path. No public `Source` trust field or `assemble` signature changed. Linux `openat2` with `RESOLVE_BENEATH | RESOLVE_NO_MAGICLINKS | RESOLVE_NO_SYMLINKS`, `O_NOFOLLOW | O_NONBLOCK`, opens substitution targets under that fd, rejecting replaced ancestors, nested symlinks and leaves; a missing source-to-root binding fails closed without falling back to a pathname reopen. A renamed source directory cannot grant reads through an external replacement of its old path. The existing 64 KiB + 1 bound, descriptor-checked regular file and UTF-8 checks remain.
- Direct public `substitute`/`assemble` callers without an admitted root independently open and verify every ancestor of the supplied trusted source directory with the same strict Linux resolver, pin that directory for target reads, and reject replaced ancestors. This explicitly relies on the caller's `trusted` decision, rather than borrowing the application's admitted-root authority.
- Fake-provider actual binary: an explicitly configured external **global** root with a nested regular `{file:nested/key}` succeeds and produces a Responses request; replacing that nested directory with an external symlink fails before any subsequent provider request, with no fixture key in stderr. Bare actual `oc` PTY shows the configuration failure, contains no fixture key in captured output, sends no provider request, creates no data root, and exits on `q`. Existing V07a global/local symlink and V07a preflight cases still pass. No secret contents are printed in these errors or TUI output.
