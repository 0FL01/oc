The transfer's user creation uses its actual turn-ID epoch. Assistant completion
is an explicitly **derived display endpoint = that epoch + actual recorded elapsed
duration**, not a claimed recorded wall-clock completion event. Assistant creation
uses the same admission coordinate; streamed time is omitted. These coordinates
preserve the real footer durations **147, 99, 134, 221, 237, 173ms**, without changing
their values to obtain equality. DCP wrapper creation uses stored whole-second
compression-block creation time. All IDs and fields retain native source traces.

Required original session tokens sum recorded per-turn display usage; required
zero cost is reference schema scaffolding because the native offline fixture
recorded/configured no price. Neither is a provider billing claim. Import's
`time.updated` remains the real per-import time, and its resolved project ID is
retained in the audit. Absolute message-event timestamp equivalence is a remaining
schema gap; this is source-derived **display** equivalence.
