## Implemented

- Native Unicode grapheme-boundary draft editor with byte-offset cursor/selection, multiline movement, Home/End, word movement/delete, Backspace/Delete, bounded undo/redo and bounded history recall at the editor's vertical boundary when the draft is nonempty. `unicode-segmentation` and `unicode-width` are production dependencies already present transitively in the lockfile. The application remains the sole submission/history owner; the pending receipt retains its immutable draft/revision. Navigation and modal focus do not bump that revision. Acceptance clears the editor only when its draft revision still matches and cancellation is not pending.
- Shared grapheme-width row layout for displayed prompt, selected spans and terminal caret; view follows caret through long drafts and exact-width rows have a following caret row. Dialog open/close and Model→Variant replacement leave draft/caret/selection in the prompt editor. Bracketed paste is one undoable insertion; control characters are filtered and CRLF is normalized. The application input budget is 1 MiB; oversized input produces a visible truncation note. Modal search retains its 512-byte budget and now reports truncation.
- Focus routing: modal consumes key/paste before editor; Ctrl+P moves the focused select upward instead of reopening it. Root leader Ctrl+X then supported L/N/M/B actions uses the existing command registry. Enter submits, Ctrl+J and supported Shift/Ctrl/Alt+Enter insert newlines, key releases are ignored, repeat Enter/shortcuts cannot duplicate side effects. Unknown Ctrl/Alt text does not leak as printable input. Ctrl+C remains root exit to preserve the existing cancellation/shutdown contract; Esc cancels a busy turn or dismisses a modal. Ctrl+D deletes in a nonempty editor and exits at an empty root.

Pinned source for key defaults: `anomalyco/opencode@2670273ff17da96f85c5826ced57aa1b368754fa`, `packages/tui/src/config/keybind.ts` (U02, fetched from the raw GitHub URL). The source defines input newline, movement, word, selection, undo, dialog selection, leader and history defaults. Only the actions backed by this native UI/application are exposed.
