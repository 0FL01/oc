Current [Zen docs](https://opencode.ai/docs/zen/#how-it-works) require sign-in and a Zen API key; whether this 403 is solely missing entitlement or also deployed client policy is unknown. Go header guidance is not Zen access permission. No credential was read from product, authoring-agent config or secrets.env, and no UA/Origin spoof, `Bearer public`, retry, model switch or second POST was attempted.
