# T48 — official direct Zen Free Chat qualification

## Result

**ZEN01 PASS, ZEN02 PASS, ZEN03 BLOCKED_LIVE.** Implementation commit `0c47aeb` adds a single native Chat Completions route for the selected `opencode` provider; no npm execution, Responses-Zen, Go, System One, static production model IDs or cross-protocol fallback. Both public catalogs are rechecked before **each** Chat POST (initial, tool continuation, title and child), and eligibility is removed on price/availability/protocol/metadata failure. Keyless (and an explicit `public`) sends the official anonymous marker `Authorization: Bearer public`, mirroring the upstream plugin; a real key is sent as its own bearer. The marker grants nothing — the gateway decides — and it is not the cause of the observed refusal. HTTP redirects, reserved header spoofing, untrusted DNS, incomplete tools and raw error bodies are refused. `oc/<version>` and the actual conversation's stable session ID identify the native client truthfully. T44 remains owner-paused; OpenProxy Responses and its A04/T27 gates are unchanged.

The owner-approved direct text-only smoke selected `big-pickle` explicitly from the then-current verified public intersection. It issued two public catalog GETs followed by **one** direct POST to `/zen/v1/chat/completions`, received sanitized **HTTP 403 Forbidden**, and stopped. Follow-up RECON from the pinned OpenCode v2.0.15 sources plus three bounded synthetic probes established the cause: the deployed gateway refuses the free tier to every non-OpenCode client with `403 FreeTierError: OpenCode's free tier can only be used from within OpenCode`, with or without the anonymous marker and with the full official header shape under our own values. This is intentional provider policy (corroborated by public issue reports), so no honest configuration unlocks it. No credential was read from product, authoring-agent config or secrets.env; no UA/Origin spoof, identity forgery, retry or model switch was attempted, and no raw response body was committed. Full detail: `evidence/T48/free-tier-gate.md`.
