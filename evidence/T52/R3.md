# T52 R3 — Runtime slices

## Result

Root keeps `Runtime<'a>` with the same borrowed Db, locks, published state,
active lease, counters, reports/policy and public entries. Production is split
into turn/admission/tool/child completion, active context/DCP/compression and
generation-owned MCP attach/call/close. Existing compaction engine, its tests
and tool_stream are unchanged. Two inline identity/VIS38 packs now live in
`runtime/tests.rs`, with the extra `runtime::tests::` prefix mapped in R7.

Public facade/sibling helper paths remain explicit re-exports with their old
visibility. Private cross-part methods/helpers are owner-scoped only as needed.
McpGeneration remains runtime-private: entries/warnings support turn/facade
callers, and its fields/type are owner-scoped for the existing compaction MCP
budget fixture, rather than adding a test constructor or exposing a public API.

- Adapter integration targets: runtime 91 PASS, subagent 14, dcp_atomic 4,

- Binary targets: dcp_runtime 2, mcp_application 27, recovery_startup 3 PASS.
- `cargo clippy -p oc-adapters --all-targets --locked -- -D warnings`: PASS.
- Supplemental base relocation review: 140 runtime functions retain

  unmodified compaction/tool_stream files and callbacks/drop implementations.
- fmt/diff checks PASS. No schema/wire/digest, default/timing/cap, algorithm,
  admission, lock/await/drop or effect ordering edits.

## Risks

Initial compiler failures identified private child seams and the existing MCP
compaction test's struct construction; only required owner scopes changed.
The first full mcp_application run had one 2-second UI timing failure in
`v05_pending_unicode_edit_keeps_one_owner_and_retry` after its modal sequence.
Inspection found the assertion shares an earlier deadline, not a new Runtime
control branch; isolated unchanged rerun passed in 0.83s (cancel/reap 257ms),
then the full unchanged 27-case target passed. No test timeout/assertion or
production body was changed to obtain that result. Final workspace gate will
run it again. Live/server-dependent ignored tests were not activated for this
mechanical relocation; existing membership must remain identical.
