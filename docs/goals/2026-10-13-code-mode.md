# T60 — Code Mode (`execute`) на нативном Rust-интерпретаторе

> Предметный справочник, не execution-инструкция. Исторические labels/status не задают очередь работ.
> Текущий scope/workflow — [AGENTS](../../AGENTS.md); открытые outcomes — [GOAL](../../GOAL.md).

Status: complete (2026-10-14; current-source qualification at `366039687`).

Owner amendment 2026-10-13. Владелец снял исключение «Code Mode interpreter /
`execute` не выставляются модели» и выбрал:

1. **Движок** — собственный интерпретатор подмножества JavaScript на Rust (как донор:
   v2.0.12 `packages/codemode` — Acorn + свой AST-интерпретатор, не V8/QuickJS).
   В production нет Node/Bun/JS-host и нет встроенного JS-движка-зависимости.
2. **MCP по умолчанию — в Code Mode, как у донора.** Без `codemode` или с
   `codemode: true` инструменты сервера уходят из прямого списка в каталог
   `execute`; `codemode: false` оставляет сервер прямым. D04 superseded.
3. **`fetch` в программе** — через владельца `webfetch` (egress/SSRF guards,
   redirects, deadline, body cap), разрешение — действие `webfetch` на URL.

## Контракт

- **R1 Tool.** `execute`, схема `{ code: string }`; описание = инвариантный текст
  донора (`core/src/codemode/tool.ts`) + отрисованный каталог. Выставляется, только
  если каталог не пуст и `execute` не запрещён целиком; central module grant Allow,
  явные Ask/Deny пользователя сохраняют силу.
- **R2 Каталог.** `tools.<server>.<tool>` (bracket notation для не-идентификаторов),
  TS-подобные сигнатуры из JSON Schema с JSDoc, бюджет ~2000 токенов и `search(...)`
  по донорскому ранжированию. Запрещённые целиком инструменты в каталог не попадают.
- **R3 Язык.** Top-level `await`/`return`, финальное выражение — результат; let/const/
  var, функции/стрелки/closures, классы (поля, static, extends, super, accessors),
  destructuring/spread/rest, шаблоны (включая tagged), optional chaining, `??=` и т. п.,
  labels, switch, try/catch/finally, генераторы и async-генераторы, `for await`.
  Отклоняются с `UnsupportedSyntax`: import/export, private `#x`, BigInt, `with`,
  `new.target`, static blocks. Таймеры, `eval`/`Function`, `require`, process API —
  `ReferenceError` с объяснением.
- **R4 Stdlib.** Object/Function/Symbol/Boolean/Error*, Array, String (UTF-16
  семантика), Number, Math, JSON, RegExp (`regress`, UTF-16), Map/Set/Weak*, Date,
  Promise (all/allSettled/race/any/withResolvers), URL/URLSearchParams/Headers,
  TextEncoder/Decoder, atob/btoa, Uint8Array (+base64/hex), crypto, console.
- **R5 Граница данных.** Как таблица донора: JSON-семантика, promise awaited, Set →
  array, URLSearchParams → строка, Error → `{name, message, ...own}`, Uint8Array
  отклоняется, own `__proto__` отбрасывается. Результат форматируется как
  `formatResult` донора (value, `Warnings:`, `Logs:`).
- **R6 Хост.** Вызовы `tools.*` и `fetch` возвращают Promise и выполняются
  конкурентно (до 8 одновременно). Каждый вложенный вызов проходит общий
  `admit_tool` (permissions, approval с invocation-id `<call>#<n>`, recheck) и
  существующий MCP lease под операцией `execute`; без consumer Ask → ошибка в
  программе, не turn-level сбой. Ошибки инструментов — исключения программы.
- **R7 Guards.** Бюджет шагов (по умолчанию 50M), отмена turn между шагами и в
  ожидании хоста, проверка нативного стека (RangeError), лимиты строк 16 MiB,
  массивов 10M, pending promises 10k, логов 1 MiB; Rc-циклы разбираются после
  программы. Long Horizon: это resource guards, не round stops.

## Объявленные отличия от донора

- Лимиты включены всегда (у донора `limits` не задаются).
- `opencode_*` остаются прямыми (контракт T50), не входят в каталог.
- Каталог доставляется в описании `execute`, а не отдельным instructions-сообщением
  с diff-обновлениями; изменение каталога меняет tool definition следующего запроса.
- Remote MCP не добавляет `?codemode=false`; executor-exclusion plugin не перенесён —
  `codemode: false` покрывает оба случая.
- Local time = UTC, `String.prototype.normalize` возвращает строку без изменений,
  порядок microtasks приближённый (await всегда уступает очередь), один матч RegExp
  не прерывается (как у донора).
- `fetch` body больше 1 MiB отклоняется, а не обрезается.
- Вложенные вызовы не становятся отдельными durable tool ops/карточками TUI; их
  эффект — часть операции `execute`. Узко superseded 2026-10-14: вместо generic
  карточки — inline строки вызовов и окно `execute` по
  [T44/VIS46](../../tui-recovery/T44_CONTRACT_AMENDMENT.md#code-mode-execute-parity--vis46-2026-10-14)
  (pending/NOT_RUN); T60 completion ниже не меняется.
