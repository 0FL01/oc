# M4 — DCP и MCP

Canonical definitions/dependencies/acceptance ownership находятся в `planning/tasks.json`. Phase содержит T17–T21.

- **T17–T19:** immutable raw history, durable DCP projection, range/protections, effectiveness и controls. Полная runtime recovery квалифицируется в T24.
- **T20:** remote MCP exact configured URL/protocol, fake server и reusable live search harness.
- **T21:** stdio lifecycle с bounded stderr, secret-free child environment и zero spawn/probe при `enabled:false`.

DCP и discovery остаются compiled modules; не добавлять JS hooks, generic summarizer или Code Mode.
