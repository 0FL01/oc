Owner-направление (2026-09-21): сначала убрать owner-visible config warnings и искусственные лимиты,
затем полностью реализовать subagent system по upstream `opencode` tag `v2.0.12`.

## Задачи

- **T43** — config compatibility parity + удаление лимитов + subagent system.
  - R1: 7 owner-visible warnings устранены (YAML-комментарии, glob-map `permission.external_directory`,
    `license`/`compatibility` в skills, каталог без `SKILL.md`, `command.agent`/`subtask`,
    `agent: file too large` 30 KiB, `command: file too large` 41 KiB).
  - R2: искусственные size-лимиты убраны (upstream их не имеет); остаётся один общий
    `MAX_TOTAL_BYTES = 4 MiB` и щедрые serving-капы `COMMAND_BYTES_CAP`/`SKILL_BODY_CAP` = 1 MiB.
  - R3: subagent system по upstream v2.0.12 (spawn/child sessions/notices/reap/permissions/
    command routing/DCP `allowSubAgents`).
  - R4/R5: коммит+push каждого среза; workspace gates зелёные.

## Порядок срезов R3 (из upstream-плана)

1. Config admission (`mode: subagent|all`, command `agent/model/subagent/subtask`).
2. Child persistence (SQLite: `parent_id`/`agent`/`model`/`title`, `children_of`).
3. Catalog/route plumbing (полный agent catalog, route ordering agent → model, `subagent_depth`).
4. Foreground `subagent` tool (fake-SSE tests: spawn/result/depth/permission/cancel).
5. Concurrent foreground/background + notices/reap/recovery (bounded owned jobs;
   background progresses while parent is active; no blanket restart → interrupted).
6. Command routing (upstream `command-subagent` semantics: inline vs child).
7. DCP `allowSubAgents` (default true, explicit false/global/manual/Deny gates,
   active-task protection and session-isolated long-horizon compression).
8. TUI/history (child rows, navigation).

## Linux host/workspace environment — T45 / R7 (owner-approved 2026-09-27)

R7 in the [M8 contract](../docs/goals/2026-09-21-config-compat-and-subagents.md#environmentcontext-references--r7)
is a Linux-only extension of prompt/context assembly. Extended host metadata is
our native addition, not a donor parity claim. Approval is not implementation PASS.

1. Collect native host facts: uname/gethostname, selected os-release fields,
   effective UID/GID, machine/process architecture, process width and available
   CPU parallelism. No root, sudo, additional capabilities or shell subprocesses.
2. Compose workspace facts from existing owners: current directory, project root,
   Git repository yes/no, actual configured shell and approved temp directory.
3. Render one bounded environment/date layer independently of agent.system;
   reuse it for primary and child requests. Implement the missing base harness
   fallback for an empty profile system; custom system replaces the base prompt,
   not the environment layer. Adapt guidance to real native tools.
4. Refresh on restart/workspace change; preserve one snapshot per request and
   existing immutable generation boundaries. Avoid duplicates in continuation.
5. Verify collector fixtures, fake-provider requests and the actual release
   binary under non-root with no effective capabilities. Unavailable optional
   metadata must not block startup; metadata does not grant tool/file access.

Static execution identity belongs in the prompt. Free RAM/disk/load and toolchain
versions are measured on demand for the current task. Never project the entire
environment, raw /proc files, machine-id or network configuration. A13 joins
T45's existing gates; task statuses and dependencies remain unchanged.

R3/R8–R10 in the M8 contract supplement R6/R7. Do not condense away requirements
or conflate donor semantics with native additions. Pinned references are in the
contract; earlier S5/S7/non-goals are amended, not a waiver of concurrency.

1. **R3 / SUB01–SUB02:** per-session owned scheduling; default foreground batch
   overlap and immediate background progress/automatic notice, command routing,
   durable restart/delivery and cancel/shutdown. Preserve native unknown-effect
   safety and parent-child policy narrowing; donor recovery is at-least-once.
2. **R10 / PRM01:** shared base/custom-system/environment/tools/skills/AGENTS
   assembler. Initial baseline, chronological updates/removals, nested read,
   restart/compaction/Revert reconciliation, immutable generation/trust boundary.
3. **R8 / CTX02:** independent stable message IDs and effective child capability
   preview. Guidance separates automatic own-profile/workspace/tools/skill metadata
   from caller-provided task/findings/history; do not duplicate bodies/schemas.
4. **R8 / CTX01:** optional context_message_ids, exact quoted user data, active
   parent branch/revision/cutoff validation before admission, chronology/dedup,
   budget and immutable durable task/pack snapshot. No parent transcript/system
   inheritance, unsupported attachments or silent truncation.
5. **R9 / DCP10:** default child compress true, narrow Explore grant, false/off/
   manual/deny gates, per-session DCP state, active task/pack protection and release
   on terminal completion with safe recovery reinstatement. No lifetime fixed packs.
6. **R9 / DCP11:** sustainable repeated recompression and bounded live block queries,
   not higher recursion caps/full-archive materialization. Freeze offline load
   before qualification; compare equal active projections over growing archives,
   root/parallel children and restart, without a product call-count lifespan limit.
