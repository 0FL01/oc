- **T43** — config compatibility parity + удаление лимитов + subagent system.
  - R1: 7 owner-visible warnings устранены (YAML-комментарии, glob-map `permission.external_directory`,
    `license`/`compatibility` в skills, каталог без `SKILL.md`, `command.agent`/`subtask`,

    `MAX_TOTAL_BYTES = 4 MiB` и щедрые serving-капы `COMMAND_BYTES_CAP`/`SKILL_BODY_CAP` = 1 MiB.
  - R3: subagent system по upstream v2.0.12 (spawn/child sessions/notices/reap/permissions/
    command routing/DCP `allowSubAgents`).
  - R4/R5: коммит+push каждого среза; workspace gates зелёные.

## Порядок срезов R3 (из upstream-плана)

1. Config admission (`mode: subagent|all`, command `agent/model/subagent/subtask`).
2. Child persistence (SQLite: `parent_id`/`agent`/`model`/`title`, `children_of`).
3. Catalog/route plumbing (полный agent catalog, route ordering agent → model, `subagent_depth`).
4. Foreground `subagent` tool (fake-SSE tests: spawn/result/depth/permission/cancel).
5. Concurrent foreground/background + notices/reap/recovery (bounded owned jobs;
   background progresses while parent is active; no blanket restart → interrupted).
6. Command routing (upstream `command-subagent` semantics: inline vs child).
7. DCP `allowSubAgents` (default true, explicit false/global/manual/Deny gates,
   active-task protection and session-isolated long-horizon compression).
8. Typed TUI/history child lifecycle/family/navigation projections (T45);
   full visual/interactive/color/animation qualification T44/VIS39, не второй UI owner.
