# Roadmap M9 — TUI pixel parity с opencode v2.0.12

Owner-направление (2026-09-21): полностью скопировать интерфейс оригинального opencode 2
(`https://github.com/anomalyco/opencode/tree/v2.0.12`).

Frozen contract: [docs/goals/2026-09-21-tui-pixel-parity.md](../docs/goals/2026-09-21-tui-pixel-parity.md).

## Задачи

- **T44** — TUI pixel parity (active).
  - VIS34 включает утверждённый 2026-09-27 compaction config/runtime parity:
    nonfatal legacy `prune` diagnostics, `auto`/manual/overflow semantics,
    TS token estimates и checkpoint guards; затем existing paired UI/replay
    qualification. Контракт и срезы — в [T44 amendment](../tui-recovery/T44_CONTRACT_AMENDMENT.md#compaction-configurationruntime-parity--дополнение-к-vis34).
  - R1: recon-артефакты (`evidence/tui/upstream-inventory.md`, `evidence/tui/current-gaps.md`).
  - R2: тема/палитра (точные значения из `packages/theme/src/tui/**`).
  - R3: геометрия layout (header / message stream / editor / status) + resize.
  - R4: рендер сообщений (markdown, reasoning, tool cards, diffs, ошибки).
  - R5: интеракции (keymap, command palette, диалоги, editor, hints).
  - VIS37: обязательный question UI/card parity по [amendment](../tui-recovery/T44_CONTRACT_AMENDMENT.md#question-ui-parity--vis37).
    Сначала T50/R4/TOOL15 typed backend + реальный answer consumer и next-request
    evidence, затем T44 lower FormPrompt, single/multiple/custom, multi-question
    navigation/review, focus/draft lifecycle и question transcript/reopen/restart.
    Пinned U31–U33, full paired styled-cell/PNG; permission VIS36 это не покрывает.
    Prerequisite — question slice, не all T50 done; остальные T44 slices независимы.
  - VIS38: обязательный [DCP transcript/accounting slice](../tui-recovery/T44_CONTRACT_AMENDMENT.md#dcp-compression-display--vis38).
    Сначала real model/manual operation + durable scoped run/metrics/bar, затем
    detailed default chat card между шагами агента, display modes/showCompression,
    shared integer/K/M formatter и paired/reopen/restart/resource qualification.
    Верхний gross removed/active summary отличается от run/net saving; не считать
    covered messages/tools повторно. D05–D10 + U34, actual pinned formatter + OC2
    renderer; M/promotion и существующий toast mapping — named display differences.
    UI04 без duplicate model messages, VIS34 /compact отдельно. T45 сохраняет child/
    long-horizon algorithms, без all-T45 done-dependency; VIS38 пока NOT_RUN.
  - VIS39: обязательный [Subagent delegation parity](../tui-recovery/T44_CONTRACT_AMENDMENT.md#subagent-delegation-parity--vis39).
    T45/R3/SUB01/SUB02 minimal lifecycle/typed projection/Ctrl+B slice first, затем
    T44 inline Delegating/running/continuation/Background, durable parent notices/
    actual footers, lower Subagents composer/navigation и family/tab indicators.
    Все colors/attributes/hover/selection и animations-on phase/state sequences +
    source-specific off fallback по pinned U35–U49/U02; full paired cells/PNG/cursor.
    Launch badge/current child state и parent scanner/family busy не смешивать;
    native response-close-before-admission сохранять. Barriers, не OCR sleep300;
    reuse existing safety/replay/resource gates, no all-T45 completion dependency.
    VIS39 mandatory NOT_RUN; approval не implementation PASS, baseline/statuses intact.
  - VIS40: обязательный [MCP modal parity](../tui-recovery/T44_CONTRACT_AMENDMENT.md#mcp-modal-parity--vis40).
    T46/R5/MCP08 minimal typed Location/generation status + real async controls first,
    затем `/mcps`/palette/Search/empty/no-match, source status/Space hint logic,
    full Dialog/Select geometry/backdrop/colors/focus/details и actual effects.
    U50–U55/U02/U49, full paired cells/PNG/cursor and owner-driven transition frames;
    `Connecting …` без component spinner/shimmer. D13 visible failure/turn continuation,
    disabled zero-spawn, cleanup/caps/quarantine и native OAuth boundary сохраняются.
    No all-T46 dependency/new task/store/framework/campaign; VIS40 mandatory NOT_RUN,
    approval не backend/visual/live PASS. Остальные T44 slices независимы.
  - R6: коммит+push каждого среза, workspace gates зелёные.

- **T45** — остаток subagent system из T43 (background/notices/reap, command routing,
  concurrent foreground, default-true child DCP и sustainable compression,
  context_message_ids/capability guidance, shared prompt/AGENTS lifecycle,
  Build/Plan/custom и Linux host context). Контракт и срезы — [M8](M8.md).
  Ready без T44 done-dependency; выбор active task через progress owner, координация
  shared UI surfaces не меняет статус T44 и не создаёт circular completion gate.

- **T50** — selected native tool parity ([M8](M8.md), [contract](../docs/goals/2026-09-27-native-tool-parity.md)):
  shell background/result notices, search options, question, read images/directories,
  webfetch formats и direct model/session tools. TOOL12–TOOL19 принадлежат только T50;
  question PTY и реальные frontend effects входят в его поведенческие проверки,
  T44/VIS37 visual qualification следует после готовности question slice и остаётся
  отдельной, без all-T50 completion dependency. Не выдавать permission форму за
  question или fixture-текст websearch/execute за runtime capabilities. Task todo,
  T44 остаётся active, без circular done-dependency.

## Порядок итераций T44

1. Recon: upstream inventory + gap analysis (два @general параллельно).
2. Theme: извлечение палитры и ролей, тест на равенство значений.
3. Layout: регионы и resize, golden-снапшоты 80x24 / 120x40.
4. Messages: markdown/reasoning/tool cards/diff, снапшоты по сценарию.
5. Interaction: keymap-таблица, диалоги, command palette, editor.
6. Финализация: сверка инвентаря компонентов с upstream, доклад о отклонениях.
