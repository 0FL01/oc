# Roadmap M9 — TUI pixel parity с opencode v2.0.12

Owner-направление (2026-09-21): полностью скопировать интерфейс оригинального opencode 2
(`https://github.com/anomalyco/opencode/tree/v2.0.12`).

Frozen contract: [docs/goals/2026-09-21-tui-pixel-parity.md](../docs/goals/2026-09-21-tui-pixel-parity.md).

## Задачи

- **T44** — TUI pixel parity (active).
  - R1: recon-артефакты (`evidence/tui/upstream-inventory.md`, `evidence/tui/current-gaps.md`).
  - R2: тема/палитра (точные значения из `packages/theme/src/tui/**`).
  - R3: геометрия layout (header / message stream / editor / status) + resize.
  - R4: рендер сообщений (markdown, reasoning, tool cards, diffs, ошибки).
  - R5: интеракции (keymap, command palette, диалоги, editor, hints).
  - R6: коммит+push каждого среза, workspace gates зелёные.

- **T45** — остаток subagent system из T43 (background/notices/reap, command routing,
  DCP `allowSubAgents`, TUI child rows). Зарегистрирована, стартует после T44 либо
  параллельно по решению оркестратора.

## Порядок итераций T44

1. Recon: upstream inventory + gap analysis (два @general параллельно).
2. Theme: извлечение палитры и ролей, тест на равенство значений.
3. Layout: регионы и resize, golden-снапшоты 80x24 / 120x40.
4. Messages: markdown/reasoning/tool cards/diff, снапшоты по сценарию.
5. Interaction: keymap-таблица, диалоги, command palette, editor.
6. Финализация: сверка инвентаря компонентов с upstream, доклад о отклонениях.
