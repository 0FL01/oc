# Roadmap M10 — укрупнённые code slices

Одна структурная задача **T52**, spec: [2026-09-28-code-slices](../docs/goals/2026-09-28-code-slices.md). Текущая карта: [CODE_MAP](../docs/CODE_MAP.md). Цель — выборочно читать связный код и тесты в agent-only workflow с окном 400k, не создавать новую платформу/слой продукта.

## Порядок

На базе ddb6ae2f0 T44 active и PAUSED по владельцу; T52 зарегистрирована только как todo. Применение этого плана не разрешает исполнение и не снимает паузу. После явного resume с T52: проверить Git/status/diff и актуальный state → factual scheduling note по R0 → `python3 scripts/progress.py block --note <repo-relative-note>` для T44 → `python3 scripts/progress.py start T52`. Это временная scheduling-пауза, не failed parity gate. Не редактировать старые checkpoint leaves и не отмечать T44 done.

Срезы выполнять последовательно; внутри T52 не заводить новый task на каждый файл:

- R0: baseline/read-set, разведка, test inventory и warning-only размерный отчёт.
- R1: отдельные крупные TUI/unit suites и перенос fixture paths.
- R2: TuiState: state/facade + input/transcript/tabs/live slices.
- R3: Runtime: owner/facade + turn/context/MCP slices и отдельные unit tests.
- R4: отдельные storage/application tests; production ниже ориентира не дробить без причины.
- R5: тематические части integration targets `runtime` и `pty_t39`.
- R6: текущая карта и живые harness/source-path consumers.
- R7: общая qualification, отчёт ARCH01–ARCH05 и возврат к T44.

Каждый срез — отдельно проверяемые commits. Разведчиков можно запускать параллельно read-only; изменения в одном worktree интегрирует один coordinator. Код поведения не переписывать заодно с переносом.

Завершение T52: implementation commit → factual `evidence/T52/report.md` → `progress.py finish --note ... --evidence evidence/T52/report.md` → closeout commit. Затем по разрешённому resume вернуть T44 через `progress.py start T44`, если нет настоящего blocker/новой инструкции владельца. Неполная T52 остаётся неполной с конкретным R-срезом в handoff; ни один старый T44 gate не объявляется PASS за счёт рефакторинга.
