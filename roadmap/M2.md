# M2 — Config и tools

Canonical definitions/dependencies/acceptance ownership находятся в `planning/tasks.json`. Phase содержит T07–T11.

- **T07:** config/provenance, explicit Location trust до substitutions/resource reads/side effects, immutable generation и central permission policy.
- **T08/T09:** bounded read/search и единый apply_patch; model-facing file tools не входят в own data root и используют no-follow path policy.
- **T10:** shell process-group lifecycle и минимальный documented child environment без provider/MCP secrets.
- **T11:** GET-only webfetch с actual-dial/redirect SSRF guards.

Не исполнять plugins/commands и не строить sandbox, persistent shell manager или generic extension host.
